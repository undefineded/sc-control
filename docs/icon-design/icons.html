STORY ICONS · REDESIGN

故事机图标 · 统一风格重设计

现有四张图标的问题：画风不统一（扁平插画 / 贴纸 / 角色），配色各走一套（紫黄、黄红、珊瑚+青、蓝）， 放在同一个列表里会互相抢。下面三版共用同一套色板，区别只在「有没有底色块」和「卡通程度」。

共同规则：无描边、圆角几何；每个图标 = 主色 + 深色 + 浅色 + 一个星星黄（#FFC83D）点缀； 视觉重量一致（图形占画布 ~78%）；4px 网格对齐，38px 下仍能认出。
A 版柔和底色块、纯扁平，和首页设备图标同一套处理；B 版透明底，最轻，但小尺寸下容易散； C 版更胖的比例、更大的月亮/星星、更粗的音符，再加一点倾斜，最卡通。
备用图（儿歌/童谣）按同一规则画，但不启用。
