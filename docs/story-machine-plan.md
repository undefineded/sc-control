# 故事机接入与家长控制方案

> 状态：P0 已实现；固件 / 小程序双端构建通过，BLE 真机冒烟测试 15/15 通过。音频共存、屏幕与断电持久化待验收。
> 配套预览：[story-machine-preview.html](./story-machine-preview.html)（浏览器直接打开，可交互）。
> 界面截图：[故事机主页](./story-preview-home.png) · [家长控制](./story-preview-parent.png) · [内容管理](./story-preview-content.png)。
> 实现说明见文末「12. 本次实现」。

## 1. 目标与范围

在设备中心新增「故事机」设备，并围绕**家长控制**设计一套可落地的端到端方案：

- 小程序：故事机主页、家长控制中心、内容管理、使用报告。
- 固件：在现有 `music-demo`（ESP32-S3 故事机）上增加 BLE 控制通道、家长策略与本地强制执行。
- 原则：**策略必须由设备本地执行**。手机不在身边、蓝牙断开、设备重启后，限制仍然生效。

本期（P0）的「控制」是**近场 BLE 控制**，不是公网远程控制。若需要家长在公司也能暂停家里的故事机，需要额外引入 WiFi 配网 + 云端，属于 P2。

## 4. 家长控制功能清单

### P0（本期必须）

| 功能 | 行为 | 设备侧强制执行 |
| --- | --- | --- |
| 每日使用时长 | 可选 15/30/45/60/90 分钟或不限；播放时计时，到时自动暂停并锁定，次日额度恢复 | 计数持久化，断电不清零；锁定时忽略播放操作 |
| 睡眠时段 | 例 20:30–07:00；进入时段自动暂停并锁定，次日结束时间自动解锁 | 每次播放前与播放中检查；跨午夜正确判断 |
| 内容管理 | 故事白名单 + 音乐分类白名单；关闭的条目在设备列表中隐藏，直接选中也会被拒绝 | 位图存储在 FRAM，列表与播放双重校验 |
| 音量范围 | 家长设置下限与上限（默认 3–12 / 21 档）；旋钮和手机都只能在范围内调节，超出自动拉回 | 在 `setVolume` 入口统一 clamp 到 `[volMin, volMax]` |
| 远程暂停 / 解锁 | 家长一键暂停并显示「家长已暂停」；再次点击解除 | 锁定状态持久化，重启仍生效 |
| 使用报告 | 今日已用、剩余额度、近 7 天每日用时 | 设备保存近 7 天聚合数据，App 展示 |
| 家长 PIN | 首次绑定设置 4–6 位 PIN，进入家长控制需校验 | 设备只存加盐哈希；连续错误锁定放在 P1 |

### P1（建议下一期）

- 单次连续使用提醒（每 20 分钟提示休息）。
- 工作日 / 周末两套时长额度。
- 睡眠时段「今晚例外」。
- 亮度上限、EQ 锁定（保护听力与视力）。
- 设备端「家长 PIN」解锁：长按 NEXT+LAST 进入数字输入。
- 多家长共享：第二台手机通过绑定码加入。

### P2（需要新硬件/云服务）

- 公网远程控制（WiFi 配网 + 云端 + 账号体系）。
- 内容商店 / 云端故事库。
- 严格日历日切换：建议增加 I2C RTC（如 DS3231，可复用现有 I2C 总线）或联网 NTP。

## 5. 固件改造方案

### 5.1 新增模块

```text
src/ble.h / ble.cpp          BLE GATT 服务、协议解析、绑定与鉴权
src/parental.h / .cpp        家长策略、计时、锁定、内容位图、PIN
src/clock.h / .cpp           手机校时、单调时钟、就寝时段判断
src/lock_ui.h / .cpp         锁定遮罩、剩余时间、提示（可并入 ui.cpp）
```

`main.cpp` 增加一个统一的策略入口：

```text
每帧：Parental::tick(now, playerPlaying)
播放/暂停/选曲/调音量/进入故事：先过 Parental::allow*()
BLE 回调：只解析并入队，命令在主循环执行，避免跨任务操作 Player
```

### 5.2 强制执行点

| 入口 | 改造 |
| --- | --- |
| `Player::toggle/playIndex/next/prev` | 锁定或内容不允许时拒绝，并提示原因 |
| `Session::setVolume` / `changeVolume` | clamp 到 `min(parentVolMax, VOL_MAX)` |
| `Story::open/start` | 校验故事白名单位图 |
| `Storage::selectCategory` | 校验音乐分类白名单位图 |
| `Screen::MusicList / TrackList / StoryList` | 只绘制允许项；全部禁用时显示家长提示页 |
| `Screen::StoryPlay / Main` | 锁定遮罩优先于正常 UI，忽略按键与旋钮 |
| 设置页 | 保留亮度/旋转/EQ；不提供家长策略入口 |

### 5.3 FRAM 布局

现有占用约 `0x0000–0x00FF`。新增家长区块建议从 `0x0300` 开始，带 magic/version/CRC，便于后续升级：

| 偏移 | 内容 | 大小 |
| --- | --- | --- |
| 0x0300 | magic `PCTL` + version + flags + CRC | 8B |
| 0x0310 | 每日额度（分钟）、睡眠开始/结束、音量下限/上限、PIN 哈希/盐 | 24B |
| 0x0330 | 今日 dayKey + 已用秒数 + 锁定原因 + 今晚例外标记 | 16B |
| 0x0340 | 近 7 天：dayKey + usedSec × 7 | 56B |
| 0x0380 | 故事白名单位图（32 位）+ 音乐分类位图（32 位）+ 启用标志 | 12B |
| 0x0390 | 绑定信息：手机 token 哈希、绑定码、状态 | 32B |

总量 < 200B，FRAM 余量充足。写入策略：计时每 60 秒落盘一次，暂停/锁定/设置变更时立即落盘。

### 5.4 时间与「一天」的定义

硬件没有 RTC，这是本方案最需要明确的限制：

- 手机每次连接都会下发 Unix 时间与本地时区，固件用「校时基准 + `millis()`」推算当前时间。
- **只有校时成功后**，睡眠时段和「零点重置」才能精确执行。
- 未校时（例如断电一夜后直接开机）：沿用上次已知日期继续累计，**不提前清零**，属于保守策略，不能被孩子通过拔电绕过额度。
- 家长 App 连接后若发现日期已变化，立即执行跨日结算并同步剩余额度。
- 需要严格日历日体验时，建议下一版加 RTC；这是硬件层改动，不在本期。

### 5.5 锁定体验

设备 320×240 屏幕显示：

```text
┌────────────────────────────┐
│        家长控制中           │
│   今日故事时间已用完        │
│   剩余 00:00 · 明天见       │
│   家长可在小程序中解锁      │
└────────────────────────────┘
```

- 锁定期间：播放/选曲/旋钮全部无效，仅保留音量键？建议也禁用，避免绕过内容策略。
- 睡眠锁定显示「该睡觉啦」，远程暂停显示「家长已暂停」，原因区分。
- 解锁只允许家长 App；P1 再增加设备端 PIN 输入。

## 6. BLE 协议设计

### 6.1 GATT

| 项 | 值 |
| --- | --- |
| 广播名 | `StoryBox-XXXX`（后 4 位为芯片 ID） |
| Service | `6b7a0001-3c4d-4e5f-8a9b-0c1d2e3f4a5b` |
| Write（App→设备） | `6b7a0002-3c4d-4e5f-8a9b-0c1d2e3f4a5b` |
| Notify（设备→App） | `6b7a0003-3c4d-4e5f-8a9b-0c1d2e3f4a5b` |
| Info（只读） | `6b7a0004-3c4d-4e5f-8a9b-0c1d2e3f4a5b` |

- 采用 NimBLE-Arduino（比 Bluedroid 轻，API 简单），加入 `lib_deps`。
- 协商 MTU 247/512；小程序按 `MTU-3` 分片写入，设备端按换行符重组。
- 广播策略：开机 30 秒快速广播（100ms），之后 1s 慢广播；绑定模式下广播含 `bind` 标记。
- BLE 回调只做解析与入队，所有 Player/Storage 操作回到主循环执行。

### 6.2 消息格式

UTF-8、单行 JSON、`\n` 结尾，单条建议 < 512B：

```json
{"v":1,"id":12,"cmd":"auth","pin":"1234"}
{"v":1,"id":12,"ok":true,"data":{"token":"..."}}
{"v":1,"evt":"state","play":1,"vol":10,"story":"月亮邮递员","used":932,"limit":1800,"locked":0}
```

命令表：

| cmd | 方向 | 作用 |
| --- | --- | --- |
| `hello` | 设备→App | 固件版本、设备名、绑定状态 |
| `bind` | App→设备 | 提交屏幕上的 6 位绑定码 |
| `auth` | App→设备 | 用绑定 token 或 PIN 换取会话 |
| `sync` | App→设备 | 下发 Unix 时间、时区、日期 |
| `get` | App→设备 | 拉取状态、家长配置、内容目录 |
| `set` | App→设备 | 写入家长配置（额度/睡眠/音量/锁定/白名单） |
| `ctrl` | App→设备 | 播放、暂停、停止、上一首/下一首 |
| `report` | App→设备 | 拉取近 7 天使用数据 |
| `pin` | App→设备 | 设置/修改家长 PIN |
| `event` | 设备→App | 状态变化、锁定、额度预警、错误 |

错误码：`AUTH`、`BIND`、`LOCKED`、`BUSY`、`NOT_ALLOWED`、`BAD_MSG`。

### 6.3 绑定与鉴权

1. 首次绑定需在设备上进入「绑定模式」（开机时按住 OK+SET，或首次开机默认 2 分钟）。
2. 设备屏幕显示 6 位随机绑定码，小程序输入后完成绑定。
3. 设备保存手机 token 的哈希；后续连接用 token 鉴权，无需每次输入。
4. 家长设置写入需要 PIN 会话；普通播放控制只需已绑定 token。
5. 连续 5 次 PIN 错误锁定 5 分钟；恢复出厂需物理组合键。

> 说明：BLE 链路本身建议启用配对/绑定加密，但「Just Works」无法防中间人。对儿童玩具场景，6 位绑定码 + PIN + 近场限制足够；若安全等级更高，需要 passkey 配对。

## 7. 小程序实现方案

### 7.1 新增文件

```text
src/utils/storyBle.ts        故事机 BLE 管理器（扫描/连接/鉴权/请求响应/重连）
src/utils/storyParent.ts     家长配置默认值、缓存、差异同步
src/pages/story/index.*      故事机主页
src/pages/story/parent/index.*   家长控制中心
src/pages/story/content/index.*  内容管理
```

页面注册到 `app.config.ts`；设备中心的「故事机」卡片从「方案预览」改为正常跳转。风扇相关路由与代码不动。

### 7.2 状态与交互

- 连接状态：未绑定 / 已绑定未连接 / 已连接 / 同步中。
- 家长配置以设备为准，小程序本地只做缓存；离线时允许编辑但标记「待同步」，连接后一次性下发并回读校验。
- 家长控制入口需要 PIN；PIN 校验在设备侧完成，小程序不保存明文。
- 播放控制做乐观更新，2 秒内未收到状态则以设备回传为准。
- 断线自动重连 3 次；失败显示「请靠近故事机后重试」。

### 7.3 关键页面

故事机主页：

- 顶部：设备名、连接状态、电量/信号（如固件提供）。
- 正在播放：故事名、插画缩略图（后续可从设备拉取当前插画）、进度。
- 控制：播放/暂停、上一首/下一首、音量滑杆（限制在家长设定的范围内）。
- 故事库：受白名单过滤；点选即播放。
- 家长控制入口：盾牌图标 + 「家长控制」；今日剩余时间进度。

家长控制中心：

- 今日概览：已用 / 剩余 / 额度进度环。
- 每日时长：15/30/45/60/90/不限。
- 睡眠时段：开关 + 开始/结束时间。
- 音量范围：双滑块设置下限/上限 + 试听提示。
- 远程暂停：开关（带二次确认）。
- 内容管理：故事数 / 分类数摘要。
- 使用报告：近 7 天柱状图。
- 修改 PIN、解除绑定（需 PIN）。

内容管理：

- Tab：故事 / 音乐分类。
- 全选/全不选；显示「新增内容默认不开放」提示。
- 保存后下发位图，回读校验。

## 8. 防绕过设计

| 场景 | 处理 |
| --- | --- |
| 孩子拔电重启 | 额度、锁定、白名单、音量范围全部持久化在 FRAM |
| 蓝牙断开 / 手机不在家 | 设备本地策略继续执行 |
| 孩子乱按按键/旋钮 | 锁定期间输入被忽略，不弹设置 |
| 换一张 TF 卡 | 内容仍需匹配白名单；索引重建后依旧过滤 |
| 删除小程序 | 设备策略不依赖手机，限制仍在 |
| 修改手机时间 | 设备以最后一次校时 + 单调时钟为准，不跟随手机反复跳变 |
| 反复试 PIN | 5 次错误锁定 5 分钟，锁定状态持久化 |
| 重新绑定 | 已绑定设备需原 PIN 或物理恢复出厂 |

## 9. 风险与边界

1. **无 RTC**：断电后无法得知真实日期，睡眠时段与跨日额度依赖手机校时；已在 5.4 说明保守策略。
2. **BLE 与音频共存**：需要真机验证 BLE 连接时的音频卡顿、WiFi/BLE 共存参数与功耗。
3. **天线**：模组为 `ESP32-S3-WROOM-1U`（外置天线版本），需确认整机天线已装配并调试；否则近场 BLE 距离和稳定性可能不足。
4. **WeChat BLE 限制**：Android 需要定位权限；部分机型 MTU/通知行为差异，需要真机矩阵测试。
5. **固件体积与内存**：NimBLE + 新模块需确认 Flash/PSRAM 余量；当前 factory 分区 0x7F0000（约 8MB），体积余量充足，但仍建议做编译体积基线。
6. **FRAM 写入寿命**：MB85RC16 写入寿命极高，60 秒一次完全可接受，但仍建议变更即写、周期写结合。
7. **功耗**：BLE 广播与连接会增加待机电流；若整机为电池供电，需要实测续航并设置广播间隔策略。
8. **远程控制预期**：P0 仅近场 BLE；公网远程需 WiFi + 云端，需单独立项。
9. **内容白名单维护成本**：新增故事默认不开放，家长需要手动勾选；可在 App 内做「新内容提醒」。

## 10. 实施阶段与验收

### 阶段

1. ✅ 方案确认：功能优先级、额度默认值、BLE 方案已确认。
2. ✅ 固件家长模块：Parental + 校时 + 锁定 UI + FRAM 持久化已完成。
3. ✅ 固件 BLE：GATT、绑定、鉴权、协议、命令队列已完成。
4. ✅ 小程序：storyBle + 三个页面 + PIN/绑定流程已完成。
5. ⏳ 联调验收：真机时长、睡眠、白名单、音量、断连、重启待做。

### 验收标准

- 绑定流程 ≤ 60 秒，失败有明确提示。
- 额度误差 ≤ 1 分钟；达到上限后 2 秒内暂停并锁定。
- 断电重启后额度、锁定、白名单、音量范围全部保持。
- 蓝牙断开后所有限制仍生效。
- 白名单外的故事/分类在设备上不可见、不可播放。
- 音量始终保持在家长设定的下限与上限之间（旋钮 + App 双路径）。
- BLE 连接与传输不影响音频播放（主观无卡顿，日志无 underrun）。
- 睡眠时段跨午夜判断正确。
- 家长 PIN 校验生效；错误次数锁定留待 P1。

| `platformio.ini` | 增加 `h2zero/NimBLE-Arduino@^1.4.3`、`bblanchon/ArduinoJson@^7.0.4` |

关键行为：

- 新增 FRAM 区块 `0x0300`，保存额度、用量、睡眠、音量范围、内容位图、PIN、绑定 token 与近 7 天历史。
- 音量：`Parental::clampVolume()` 统一限制在 `[volMin, volMax]`；设备旋钮、BLE 控制、开机恢复三条路径都经过它。
- 锁定：`Parental::lock()` 返回 `DailyLimit / Bedtime / Remote`；主循环锁定后停止播放、忽略输入并绘制锁定页。
- 内容：白名单开启时，Storage/Story 的视图只暴露允许项；播放入口再次校验。
- 时间：手机 `sync` 下发 epoch + 时区；无 RTC，断电后未校时按保守累计，不提前跨日。
- 绑定：首次启动屏幕显示 6 位码；绑定成功后设备只保存 token 哈希，App 保存 token。
- PIN 兜底：已绑定但 token 丢失时，如果设置过 PIN，可在故事机主页用 PIN 授权。

### 12.4 首次使用

1. 烧录 `music-demo` 固件并插入 TF 卡，开机。
2. 未绑定设备会在屏幕显示 6 位绑定码。
3. 小程序设备中心 → 故事机 → 扫描 `StoryBox-XXXX` → 连接。
4. 输入屏幕上的绑定码，完成绑定；App 保存 token。
5. 进入「家长控制」设置 PIN、每日时长、睡眠时段、音量范围。
6. 进入「内容管理」勾选允许的故事与音乐分类并保存。

## 13. 无线开关（单片机设置页）

设置页由 4 项扩展为 8 项，右侧滚动条提示当前窗口：

| 设置项 | 行为 | 默认 |
| --- | --- | --- |
| 蓝牙广播 | 开：广播 `StoryBox-XXXX`；关：停止广播，已连接会话不受影响 | 开 |
| WiFi | 开：WiFi STA，读取 `WIFI_STA_SSID` / `WIFI_STA_PASS`；未配置时只打开射频 | 关 |
| 热点 AP | 开：SoftAP `StoryBox-XXXX` / `storybox123`，地址 `192.168.4.1` | 关 |
| 显示绑定码 | 在屏幕显示 6 位首次配对码，双击 OK 返回 | — |

- 三个开关保存在 FRAM（设置块升级为 `MPL3`，12 字节）。
- WiFi 与 AP 可同时开启（AP+STA）。
- BLE 与 WiFi 共存时保留 modem sleep，避免 ESP-IDF 断言重启。
- 真机自检已确认：AP 启动、IP 获取、BLE 广播关/开、WiFi/AP 关闭均正常。
- 未绑定设备开机显示绑定码 4 秒；手机 BLE 连接时自动切到绑定码页，直到绑定成功或断开。
- 小程序故事机主页也会读取并显示设备返回的绑定码，提供「填入」按钮。
