交互演示

  1. 点击主页「家长控制」卡片，输入 2468 通过验证。
  2. 调整每日时长或音量范围，回主页查看剩余时间与档位。
  3. 打开远程暂停，回主页查看设备锁定遮罩。
  4. 进入内容管理勾选/取消故事，保存后故事库同步变化。
